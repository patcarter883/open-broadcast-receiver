# Standby slate art

`logo.png` is a **placeholder** wordmark (white "OPEN BROADCAST", 800×91,
transparent background) standing in for the real brand logo; it is installed
into the image as `/usr/local/share/open-broadcast/standby-logo.png` and drawn
on the slate by `gdkpixbufoverlay`. Replace it with the real mark (same path in
the image, or point `--standby-assets` at a directory containing your own
`standby-logo.png`) — the file name and path are the whole contract.
